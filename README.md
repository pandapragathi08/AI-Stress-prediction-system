===========================================================
1. OVERVIEW
===========================================================

In the modern education environment, students experience high levels of stress
due to academic pressure, sleep deprivation, excessive screen time, and a lack
of balance between study and rest. Prolonged stress can result in anxiety,
depression, and poor academic performance.

To address this, our project aims to PREDICT students stress levels using
Machine Learning and provide personalized stress-relief recommendations.
The system encourages mental wellness and helps students manage their study-life
balance effectively.

===========================================================
2. OBJECTIVES
===========================================================

- Develop a web-based AI system to analyze lifestyle factors.
- Predict student stress level as Low, Medium, or High.
- Provide personalized recommendations to reduce stress.
- Promote awareness of mental health and wellness.

===========================================================
3. PROBLEM STATEMENT
===========================================================

Students often struggle with emotional and psychological stress due to academic
competition and workload. Currently, there are limited accessible tools for
early stress detection.

Our solution uses AI/ML to identify early indicators of stress and provide
timely preventive suggestions to support student well-being.

===========================================================
4. SYSTEM ARCHITECTURE
===========================================================

Step-by-step workflow:

1. Input Layer:
   - User enters data such as sleep hours, study hours, screen time, marks, mood.

2. Preprocessing:
   - Input data is cleaned and normalized for ML model processing.

3. Machine Learning Model:
   - Trained model (e.g., Logistic Regression / Decision Tree)
     predicts the stress category.

4. Output Layer:
   - Displays predicted stress level and provides a suggestion.

Example Output:
-----------------------------------------------------------
Predicted Stress Level: HIGH
Recommendation: Take a short break, avoid screens for an hour, and try meditation.
